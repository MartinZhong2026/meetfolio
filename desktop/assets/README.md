Original Meetfolio open-book artwork, MIT license as in the repository LICENSE.

Edit `meetfolio.svg`, then run `npm run icons -w desktop` from the repository root. The locked development tool exports `meetfolio.png`, all seven ICO resolutions, and the two NSIS 24-bit bitmaps. Commit these small brand assets together. They are source assets, not generated application binaries or model weights.

Do not put signing certificates or private keys here. See `docs/windows-signing.md` for installation behavior, icon-cache verification and legitimate signing preparation.
